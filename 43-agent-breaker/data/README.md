# Data for project 43

Synthetic. Generated by `_generate.py` with a fixed seed, so a rerun reproduces every file byte for byte. Nothing here comes from a real agent, customer, bank or employer.

| File | What it holds |
|---|---|
| `events.csv` | 7523 calls from 5 agents over 3 days (4320 minutes): `t_min`, `agent`, `case_id`, `outcome` (ok or fail), `failure_kind`. This is what each agent did or would have done; a breaker decides which calls reach it |
| `truth_calls.csv` | Per call: the planted `fault_id` (blank when none was active) and `harm` (1 when a fault made the call fail, go wrong or step outside scope). The breaker never reads this file; the scripts use it to score |
| `faults.csv` | The 25 planted faults: agent, kind, `truth_class`, start and end minute, intensity (a failure probability, or the length of a forced run), calls inside the fault and harmful calls |
| `controls.csv` | 4 operator actions (two engage, two release) in quiet hours, for the operator-switch run in step 4 |
| `policy.csv` | The breaker's parameters. 🟡 Every value is an assumption except `warn_fraction` and `clear_fraction`, copied from project 25 |
| `model_assumptions.csv` | 🟡 The person-on-a-schedule model in step 1 and the scoring grace times. Assumptions, not measurements |
| `example_events.csv` | 90 calls from one agent behind `python3 agent_breaker.py --demo`: two stray failures, then an outage from minute 60 to 111 |

Call rates are per agent and minute (0.80, 0.50, 0.40, 0.30 and 0.12), cut to 30 percent of that between midnight and 06:00. The baseline failure probability is 0.03.

Planted faults (25): hard outage 4, brownout 5, flapping 2, scope violation 3, silent errors 2, slow burn 2, short blip 4, long blip 2, quiet-agent noise 1. By truth class:

- `must_trip` (14): hard outage, brownout, flapping, scope violation. A breaker should stop the agent.
- `must_not_trip` (7): a short blip (3 or 4 failures in a row), a long blip (5 or 6 in a row) and two failures in three calls from the quiet agent. All are harmless. The short ones and the quiet-agent case are hard negatives. The long blips are a false alarm that a count of failures cannot avoid, on purpose.
- `hard_miss` (4): silent errors (the agent reports ok and is wrong) and a slow burn at a 0.28 failure rate. A breaker that reads outcomes is expected to miss these.

Faults sit in even six-hour slots, so each agent has at least six quiet hours between two of its faults. Flapping is placed in the day, when the volume is enough to see it. The label of each fault comes from the kind that was planted, not from the breaker's rules.
