# Data for project 28

Synthetic. Generated by `_generate.py` with a fixed seed, so a rerun reproduces every file byte for byte. Nothing here comes from a real tool catalogue, bank or employer.

| File | What it holds |
|---|---|
| `tools_base.json` | The 10 tool schemas as they stand before any pull request |
| `pr_cases.csv` | 67 pull requests: `pr_id`, `tool`, `old_schema_json`, `new_schema_json` |
| `pr_truth.csv` | The planted change per pull request: `change_kind` and `truth_class` (breaking, behavior_risk, non_breaking). The label comes from the change that was planted, not from the classifier |
| `recorded_calls.csv` | 400 calls, 40 per tool, valid under the schema before the change |
| `example_old.json`, `example_new.json`, `example_calls.csv` | The worked example behind `python3 tool_schema_drift.py --demo` (one removed enum value on `block_card`) |

Planted changes (67): rename 5, remove optional 4, add required 5, enum value removed 4, number narrowed to integer 3, upper bound tightened 4, add optional 5, enum value added 4, integer widened to number 3, reword 6, version bump only 5, default changed 4, unit swapped in a description 5, meaning flipped with no number or unit 3, rewording that keeps the same numbers 4, scale changed with the same unit word 3. The last two kinds are hard on purpose: the first tests for a false alarm, the second for a miss.
