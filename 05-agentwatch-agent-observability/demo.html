The bleed. Deployed agents fail in ways pre-LLM apps never did. Runaway tool loops can burn $5–50k per incident. Tool-call failures cascade silently. Most banks run agents with no continuous observability — they find out via the AWS bill or a customer complaint.

The fix. AgentWatch is a sidecar that ingests the agent framework's OpenTelemetry export, classifies failures under a six-deficiency taxonomy, and enforces a per-incident dollar cap. The bleed stops in minutes, not weeks. utility = (3 weeks - 6 minutes) × every deployed agent
