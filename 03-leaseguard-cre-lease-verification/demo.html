Utility delivered

Utility = (deployed-NLP error rate − LeaseGuard error rate) × field extractions per cycle

🟢 Measured on this 6-lease set: deployed pipeline 55/72 fields correct (76.4%); after LeaseGuard triage 71/72 (98.6%, counting every routed field as resolved correctly by the paralegal). 17 wrong fields: 16 routed to triage, 1 missed. 21 fields routed in total, so 5 were false flags a paralegal has to clear. The one miss is the lease_06 kick-out clause, where both models return the same incomplete value and no rule fires.

🟡 Modeled at portfolio scale (220 leases × 12 fields = 2,640 extractions per cycle): blended accuracy 88% → 98.2%, roughly 270 field errors caught per year, ~$4.2M/yr of recovered rent exposure. Assumes the public PropTech benchmarks named in the README and that paralegal triage clears flagged fields; not measured.
