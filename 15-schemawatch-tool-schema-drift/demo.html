Portfolio prototype on synthetic data, not a production case study. The generator injected every change, so the truth is known. No model is used: the diff, heuristic, validator and gate are plain rules. Every number on this page is generated from the scripts in src/.

Utility delivered

Utility = (calls broken or misread per change without SchemaWatch − with it) × schema changes per quarter

🟢 Measured on this synthetic set: 1,280 of 2,500 recorded calls are broken or misread across 45 changes (28.44 per change). With the gate holding every BLOCK and REVIEW, 169 remain (3.76 per change): the 3 meaning changes with no number or unit, which the heuristic cannot see. Replay predicted 742 of 742 broken calls with 0 false positives and 0 misses; classification matched the ledger on 41 of 45 changes.

🟡 Modeled: 12 schema changes per quarter across a 28-tool estate (an assumption, not a statistic) gives (28.44 − 3.76) × 12 = 296 calls per quarter per recorded week of exposure per change. Assumes every BLOCK and REVIEW is acted on before the release reaches the agent.
