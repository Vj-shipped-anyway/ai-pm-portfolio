# Data for project 76

Synthetic. Generated by `_generate.py` with a fixed seed, so a rerun reproduces every file byte for byte. Given names are common first names and surnames are invented from syllables. Nothing here comes from a real watchlist, bank, customer or employer, and any resemblance to a real name is chance.

| File | What it holds |
|---|---|
| `watchlist.csv` | 90 listed names for 60 entities (60 primary, 30 aliases): `entry_id`, `entity_id`, `listed_name`, `name_type` |
| `customers.csv` | 400 customer names as recorded: `customer_id`, `name` |
| `truth.csv` | `customer_id`, `truth` (match or clear), `entity_id` (the listed entity for a match), `planted_as` (the change that was planted). The label comes from the process that planted it, not from a matcher |
| `example_watchlist.csv`, `example_customers.csv`, `example_truth.csv` | The hand-written sample behind `python3 name_match_eval.py --demo` (6 listed names, 12 customers) |

Planted matches (150): format only 16, order swap 24, transliteration 22, transliteration and order 18, dropped middle name 14, initial 14, typo 14, particle joined to surname 8, three rare spelling swaps 10, alias that is not on the list 10.
Planted clear names (250): unrelated 100, listed surname with another given name 56, listed given name with a resembling surname 56, one-letter-different surname 30, exact name of a listed party 8.

Hard on purpose: three rare spelling swaps and the alias that is not listed (a matcher should miss them), the joined particle (the word matcher misses it more than edit does), and the last two clear kinds (hard negatives that alert at most thresholds).

Assumptions, all 🟡: the mix of variants above; the two swap tables in `_generate.py` (14 common pairs and 12 rare pairs, written by me, not taken from any transliteration standard); the matcher's fold table, which covers the common pairs and none of the rare ones; the targets of 10.0% false alerts on clear names and 85.0% recall; and the base rate of 1 real match in every 10,000 customers used for the modeled line. The mix in `truth.csv` (150 of 400 are matches) is not a real base rate.
